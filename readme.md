# ⚙️ LeetCode: DSA in Rust 🦀 & Python 🐍

Welcome to my personal grind repo where I solve **LeetCode problems** and explore **Data Structures & Algorithms** — written in blazing-fast ⚡ and memory-safe 🦀 **Rust**, and now also in clean, expressive 🐍 **Python**.

## 📦 What's inside?

- 🧠 Classic DSA problems (arrays, strings, trees, graphs, you name it)
- 🔐 LeetCode-style problem organization
- 🧪 Clean, testable, modular Rust code
- 🐍 Python solutions alongside the Rust ones
- 🧰 Growing toolkit of patterns, tricks & idioms in both languages

## 🚀 Why Rust & Python?

Because:
- Rust is **fast** and **safe**, and makes DSA feel like boss battles. 💥
- Python is **quick to write** and great for rapidly prototyping ideas and algorithms. 🐍
- Solving the same problems in both sharpens language-agnostic problem-solving skills.

## 🗂️ Structure

- `src/`
  - `_two_sum.rs` — LeetCode #1: Two Sum  
  - `main.rs` — Entry point for quick testing
- `python/`
  - Python solutions, organized by LeetCode ID


- Each Rust problem lives in its own module under `src/_<number>_<probilem_name>/`.
- Each Python problem lives under `python/_<number>_<probilem_name>/` (or similar).
- Organized by LeetCode ID for sanity ✅.

## 🧪 How to Run

**Rust:**
```bash
cargo run
```
Or test a specific module by editing main.rs.

**Python:**
```bash
python python/<problem_file>.py
```
